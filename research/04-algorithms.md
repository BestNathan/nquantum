# R4 · 算法、应用与量子优势

## 研究范围

- 基础算法：QFT / Shor、Grover / 振幅放大、量子相位估计。
- 量子模拟：量子化学、材料、哈密顿量演化。
- 混合启发式：VQE、QAOA、量子机器学习（需防止数据编码与经典开销被遗漏）。
- 密码学影响：公钥密码受威胁的理论边界，与实际容错资源/时间分离。
- 量子退火/模拟器：单独标注计算模型，不和通用门模型直接混合排名。

## 一项实验的合格比较

1. 定义输入规模、问题实例和目标误差/成功概率。
2. 固定资源预算（时间、资金、能耗或硬件访问）。
3. 使用强且公开的经典算法基线；不能把未优化经典代码当成最佳基线。
4. 计入数据加载、编译、排队、shots、误差缓解、经典优化与输出读取。
5. 区分理论复杂性加速、特定实验任务优势、经济实用优势。
6. 记录数据集、代码版本、随机种子、统计显著性及不确定性。

## 研究交付

算法卡（问题 → 复杂度/假设 → 硬件要求 → 真实证据 → 限制 → 可复现实验）和 benchmark 契约；不声称某个算法已取得商业优势，除非有对等条件下的原始证据。
