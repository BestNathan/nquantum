# R3 · 量子纠错与容错

## 研究目标

从“逻辑量子比特出现”走向“可连续执行、可扩展的容错量子操作”的证据链。

## 分析层级

1. **物理噪声**：门/测量/泄漏/相关错误与随时间漂移。
2. **编码**：稳定子码、surface code、color code、量子 LDPC 等；记录适用前提。
3. **综合征周期**：重复测量、ancilla、实时反馈与经典解码。
4. **逻辑存储**：码距、逻辑错误率、随码距变化及其置信区间。
5. **逻辑操作**：逻辑门、魔态工厂、编译开销与资源消耗。
6. **容错计算**：给定应用目标所需物理比特、空间时间体积、吞吐与资源估算。

## 关键指标

- Physical error probability：指定噪声模型、门/测量类型和实验协议。
- Logical error per round / per cycle：标明定义、轮数、码距、shots、解码器和是否后选择。
- Suppression ratio：在相同实验定义下比较不同码距的逻辑错误率，不能跨协议直接计算。
- Decoder latency：在线延迟、资源开销及是否满足反馈时限。
- Physical-to-logical overhead：给定代码、距离、逻辑操作和目标错误预算下的资源成本。

## 关键辨析

“单个逻辑比特演示”不是“可运行有用算法的容错机器”；低于阈值、实时纠错、逻辑门集、规模化解码分别是不同证据。所有数值必须附原始实验与条件。

## 首批问题

跨码距实验的改进是否显著？逻辑操作而非只存储的错误率怎样？需要何种物理错误率才能支持大电路？经典解码能否在目标周期内运行？
